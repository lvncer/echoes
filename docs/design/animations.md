# アニメーション一覧

## 1. ニュートラル（neutral）- 平常状態

- **あくび** - 口を大きく開けて手で覆う
- **軽い首振り** - 左右にゆっくりと首を振る
- **髪をかき上げる** - 手で前髪や髪の毛を整える
- **腕組み** - 両腕を胸の前で組む
- **足の重心移動** - 片足から另一只足へ体重を移す
- **軽い肩回し** - 肩をほぐすように回す
- **時計を見る動作** - 手首を見て時間確認
- **軽いストレッチ** - 腕を上に伸ばす
- **頬杖をつく** - 手で頬を支える
- **軽く振り返る** - 何かを確認するように後ろを見る

## 2. 喜び（happy）- 嬉しさ・楽しさ

- **拍手** - 両手を合わせて叩く
- **小さくジャンプ** - 嬉しさで軽く跳ねる
- **ガッツポーズ** - 片手または両手を上に突き上げる
- **手を振る** - 元気よく左右に手を振る
- **くるっと回転** - その場で一回転
- **胸に手を当てる** - 感動を表現
- **スキップ動作** - 軽やかに歩く
- **両手を広げる** - 開放感を表現
- **頭を軽く振る** - 喜びで首を振る
- **親指を立てる** - サムズアップ

## 3. 悲しみ（sad）- 悲しさ・落ち込み

- **うつむく** - 顔を下に向ける
- **肩を落とす** - 肩が垂れ下がる
- **顔を手で覆う** - 両手で顔を隠す
- **深いため息** - 大きく息を吐く
- **座り込む** - その場にしゃがみ込む
- **涙を拭く動作** - 手で目元を拭う
- **胸を抱える** - 自分を抱きしめる
- **壁にもたれかかる** - 支えを求めるように
- **ゆっくりと首を振る** - 否定的な首振り
- **膝を抱える** - 体を小さくまとめる

## 4. 怒り（angry）- 怒り・不満

- **拳を握る** - 両手でグーを作る
- **腰に手を当てる** - 威圧的なポーズ
- **指差し** - 相手を指で指す
- **足を踏み鳴らす** - 地面を強く踏む
- **腕を大きく振る** - 感情的なジェスチャー
- **頭を激しく振る** - 強い否定
- **胸を張る** - 対抗的な姿勢
- **手をひらひら振る** - 拒絶の動作
- **深呼吸** - 怒りを抑えようとする
- **髪をかきむしる** - イライラを表現

## 5. 驚き（surprised）- 驚き・意外感

- **後ずさり** - 一歩後ろに下がる
- **手を口に当てる** - 驚きを表現
- **目を見開く** - 大きく目を開ける動作
- **両手を上げる** - 降参のようなポーズ
- **振り返る** - 急に後ろを見る
- **立ち止まる** - 急に動きを止める
- **胸に手を当てる** - 心臓の鼓動を抑える
- **首をかしげる** - 困惑を表現
- **軽く飛び跳ねる** - びっくりして跳ねる
- **手をひらめく** - 理解した瞬間の動作
