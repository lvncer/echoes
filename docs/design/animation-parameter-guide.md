# VRM アニメーション パラメーター調整ガイド

## 基本理解

### 座標系

- X 軸: 左右（負の値 = 左、正の値 = 右）
- Y 軸: 上下（負の値 = 下、正の値 = 上）
- Z 軸: 前後（負の値 = 前、正の値 = 後）

### 回転（rotation）の単位

- ラジアン（radian）で指定
- 1 ラジアン ≈ 57.3 度
- 一般的な角度の目安：
  - 0.5 ラジアン ≈ 29 度
  - 1.0 ラジアン ≈ 57 度
  - 1.5 ラジアン ≈ 86 度

## ボーン構造と初期位置

### 腕・手のボーン階層

```md
Shoulder（肩）
↓
UpperArm（上腕）
↓
LowerArm（前腕・肘）
↓
Hand（手）
```

### 初期位置（ニュートラル状態）

- **手の位置**: ほぼ真下に向いている
- **肩**: リラックスした状態
- **上腕**: 体の横に下がっている
- **前腕**: まっすぐ下に伸びている

## あくび動作の改善ポイント

### 現在の問題点

1. **手の角度がおかしい**
2. **手が顔に十分近づかない**

### 修正方針

手を口元に自然に持っていくためのボーン調整：

#### 段階的な動作

1. **肩を上げる** → RightShoulder の X 軸回転を増やす
2. **上腕を前に振り上げる** → RightUpperArm の X 軸を負の値に
3. **肘を曲げる** → RightLowerArm の Y 軸回転を増やす
4. **手首を調整** → RightHand で最終的な角度調整

### 具体的なパラメーター例

#### 手を口元に持っていく場合

```typescript
// より自然な手の動き
RightShoulder: { rotation: [0.3, 0, 0] },      // 肩を少し上げる
RightUpperArm: { rotation: [-0.8, 0.2, 0.3] }, // 前に振り上げて少し外側に
RightLowerArm: { rotation: [-0.5, 0, 1.5] },   // 肘を大きく曲げる
RightHand: { rotation: [0, -0.2, 0] },         // 手首を自然に調整
```

## ブレンドシェイプ設定

### 口の形（あくび用）

- **A**: あ形（縦に開く）0-1.0
- **O**: お形（丸く開く）0-1.0
- **組み合わせ**: A=0.8, O=0.6 で大きなあくび

### 利用可能なブレンドシェイプ

現在の VRM モデルで使用可能なもの：

- 口の形: A, I, U, E, O（または日本語版：あ、い、う、え、お）
- 感情: Joy, Angry, Sorrow, Fun
- まばたき: Blink, BlinkL, BlinkR

## 調整のコツ

### 1. 段階的調整

- 一度に大きく変更せず、0.1-0.2 ずつ調整
- 一つのボーンずつ変更して効果を確認

### 2. 階層を意識

- 親ボーン（Shoulder）→ 子ボーン（UpperArm）の順で調整
- 上位の変更は下位にも影響する

### 3. 自然な動作の参考

- 実際に手を口元に持っていく動作を鏡で確認
- 肩 → 上腕 → 肘 → 手首の順番で動く

### 4. タイムライン調整

- 各キーフレームの時間を調整して動作の速度変更
- 開始は遅く、途中は早く、終了は遅く（ease-in-out）

## よくある問題と解決法

### 手が変な方向に動く

- **原因**: UpperArm の Y 軸回転が適切でない
- **解決**: Y 軸を-0.5〜0.5 の範囲で調整

### 肘の動きが不自然

- **原因**: LowerArm の Z 軸回転が小さすぎる
- **解決**: Z 軸を 1.0〜1.5 に増やす

### 手首がぐらつく

- **原因**: Hand と LowerArm の回転が干渉
- **解決**: Hand の回転を小さな値に抑える
