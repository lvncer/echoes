# 感情・アニメーション対応表

## 概要

Echoes アプリケーションにおける感情解析結果とアニメーション表現の対応関係を定義します。
AI 応答テキストから感情を自動判定し、それに応じた VRM モデルのアニメーションを実行します。

## 感情分類システム

### 基本感情（5 種類）

| 感情 ID | 感情名       | 英語名    | 説明                     |
| ------- | ------------ | --------- | ------------------------ |
| 1       | ニュートラル | neutral   | 平常状態・感情的に中立   |
| 2       | 喜び         | happy     | 嬉しさ・楽しさ・満足感   |
| 3       | 悲しみ       | sad       | 悲しさ・落ち込み・失望感 |
| 4       | 怒り         | angry     | 怒り・不満・苛立ち       |
| 5       | 驚き         | surprised | 驚き・意外感・困惑       |

## 感情別アニメーション詳細

### 1. ニュートラル（neutral）

**概要**: 感情的に中立な状態。リラックスした自然な立ち姿勢

**アニメーション構成**:

- **表情**: 全てのブレンドシェイプを 0.0 に設定
- **ジェスチャー**: 基本姿勢（頭・肩・背骨を自然な位置）
- **持続時間**: 1 秒（1000ms）
- **ループ**: なし

**適用場面**:

- 会話開始時のデフォルト状態
- 感情的でない事実説明
- システムメッセージ
- 感情判定スコアが低い場合

---

### 2. 喜び（happy）

**概要**: 微笑みと軽やかな動作で喜びを表現

**アニメーション構成**:

- **表情**:
  - happy: 0.6-0.8（笑顔）
  - 軽い瞬き（blinkLeft/Right: 0.3）
- **ジェスチャー**:
  - 軽いうなずき（Head: Y 軸 0.1 回転）
  - 肩を少し上げる（Shoulder: Z 軸 ±0.05 回転）
- **持続時間**: 1.5 秒（1500ms）
- **ループ**: なし

**適用場面**:

- 褒められた時
- 良いニュースを伝える時
- ユーザーの成功を祝う時
- ポジティブな反応

**トリガーキーワード例**:

- 嬉しい、楽しい、良い、素晴らしい、ありがとう、おめでとう

---

### 3. 悲しみ（sad）

**概要**: 落ち込んだ表情と控えめな動作で悲しみを表現

**アニメーション構成**:

- **表情**:
  - sad/sorrow: 0.6-0.7（悲しい表情）
  - frown: 0.5（眉を寄せる）
- **ジェスチャー**:
  - 頭を少し下げる（Head: X 軸 -0.2 回転）
  - 肩を落とす（Shoulder: Z 軸内向き回転）
  - 前かがみ姿勢（Spine: 軽い前傾）
- **持続時間**: 2 秒（2000ms）
- **ループ**: なし

**適用場面**:

- 悪いニュースを聞いた時
- ユーザーの失敗に共感する時
- 申し訳ない気持ちを表現する時
- 慰めの言葉をかける時

**トリガーキーワード例**:

- 悲しい、辛い、残念、申し訳、大変、失敗

---

### 4. 怒り（angry）

**概要**: 強い表情と力強いジェスチャーで怒りを表現

**アニメーション構成**:

- **表情**:
  - angry/anger: 0.7-0.8（怒った表情）
  - mad: 0.6（激怒）
  - frown: 0.8（深い眉寄せ）
- **ジェスチャー**:
  - 強いうなずき（Head: 大きな上下動）
  - 両拳を握る動作（Hand 回転）
  - 肩を張る（Shoulder: 外向き回転）
  - 直立姿勢（Spine: 真っ直ぐ）
- **持続時間**: 1.8 秒（1800ms）
- **ループ**: なし

**適用場面**:

- 不正や理不尽な状況への反応
- 強い否定・反対の意思表示
- 警告・注意喚起
- 正義感を表現する時

**トリガーキーワード例**:

- 怒り、ムカつく、許せない、ひどい、最悪、反対

---

### 5. 驚き（surprised）

**概要**: 大きな動作と表情で驚きを表現

**アニメーション構成**:

- **表情**:
  - surprised/surprise: 0.8（驚いた表情）
  - shocked: 0.7（ショック）
  - 目を大きく開く
- **ジェスチャー**:
  - 頭を後ろに引く（Head: X 軸後方回転）
  - 両肩を上げる（Shoulder: Z 軸上向き回転）
  - 後ろに反る姿勢（Spine: 軽い後傾）
- **持続時間**: 1.3 秒（1300ms）
- **ループ**: なし

**適用場面**:

- 予想外の情報を受けた時
- 新しい発見や驚くべき事実
- ユーザーの意外な発言への反応
- 困惑や当惑の表現

**トリガーキーワード例**:

- 驚き、びっくり、まさか、信じられない、意外、突然

## 組み合わせアニメーション

### 基本アニメーション（常時実行）

1. **瞬き**: 2-6 秒間隔で自動実行
2. **呼吸**: 連続実行（胸の上下動）

### ジェスチャーアニメーション（手動・自動トリガー）

- **手の動き**: 指差し、手振り、拍手
- **頭の動き**: うなずき、首振り、傾げ
- **体の動き**: 前傾、後傾、肩すくめ

## 感情強度（Intensity）システム

### 強度レベル

- **0.0-0.3**: 微弱（subtle）
- **0.4-0.6**: 中程度（moderate）
- **0.7-0.9**: 強い（strong）
- **1.0**: 最大（maximum）

### 強度による調整

- ブレンドシェイプ値: `基本値 × 強度`
- ボーン回転角度: `基本角度 × 強度`
- アニメーション速度: `基本速度 × (0.5 + 強度 × 0.5)`

## 信頼度（Confidence）システム

### 信頼度による制御

- **0.8 以上**: 感情アニメーション実行
- **0.5-0.8**: 軽微な感情表現
- **0.5 未満**: ニュートラル維持
