# 感情判定システム仕様書

## 概要

Echoes アプリケーションにおける感情判定システムの技術仕様です。
AI 応答テキストからキーワードベースで感情を自動判定し、VRM モデルのアニメーション制御に活用します。

## システム構成

### 感情解析フロー

```asc
AI応答テキスト
    ↓
テキスト正規化
    ↓
キーワード辞書マッチング
    ↓
感情スコア算出
    ↓
最高スコア感情選択
    ↓
強度・信頼度計算
    ↓
感情解析結果出力
    ↓
アニメーション実行
```

## 感情判定アルゴリズム

### 1. テキスト正規化

```typescript
private normalizeText(text: string): string {
  return text
    .toLowerCase()                    // 小文字化
    .replace(/[！？。、]/g, "")       // 句読点除去
    .replace(/\s+/g, "")             // 空白除去
}
```

### 2. キーワード辞書システム

#### 辞書構造

```typescript
interface EmotionKeywords {
  [emotion: string]: {
    primary: string[]; // 主要キーワード（高重み）
    secondary: string[]; // 補助キーワード（中重み）
    intensity: number; // 基本強度（0.0-1.0）
  };
}
```

#### キーワード重み設定

- **Primary キーワード**: 重み `2.0`（強い感情表現）
- **Secondary キーワード**: 重み `1.0`（弱い感情表現）

## スコア計算システム

### 基本スコア算出

```typescript
基本スコア = (Primary一致数 × 2.0) + (Secondary一致数 × 1.0)
```

### 感情選択ロジック

1. **最高スコア感情を選択**
2. **同点の場合**: より感情的な順序で選択
   - 順序: `angry > surprised > happy > sad > neutral`
3. **全スコア 0 の場合**: `neutral` を選択

### 強度（Intensity）計算

```typescript
強度 = Math.min(1.0, (
  (感情スコア / テキスト長) × 10 +          // 密度係数
  Math.min(感情スコア / 3, 0.3) +           // スコア係数
  強調表現倍率                               // ！？倍率
) × 基本強度)
```

**強調表現倍率**:

- `！`: 1.2 倍
- `？`: 1.1 倍
- `！！`: 1.5 倍
- 3 つ以上: 2.0 倍上限

### 信頼度（Confidence）計算

```typescript
信頼度 = Math.min(1.0, (
  感情スコア / (総スコア + 1) × 0.7 +       // 相対スコア
  Math.min(感情スコア / 5, 0.3)             // 絶対スコア
))
```

## 解析結果データ構造

```typescript
interface EmotionAnalysisResult {
  emotion: "neutral" | "happy" | "sad" | "angry" | "surprised";
  intensity: number; // 0.0-1.0: 感情の強さ
  confidence: number; // 0.0-1.0: 判定の確実性
  keywords: string[]; // マッチしたキーワード
}
```

## 履歴・文脈機能

### 解析履歴管理

- **履歴保存数**: 最大 100 件
- **記録内容**: 感情、強度、信頼度、キーワード、タイムスタンプ

### 文脈考慮解析

```typescript
文脈調整係数 = 1.0 + (前回解析との感情変化度 × 0.2)
最終強度 = 基本強度 × 文脈調整係数
```

## アニメーション連携

### 実行条件

- **信頼度 ≥ 0.8**: 感情アニメーション実行
- **信頼度 0.5-0.8**: 軽微な表現
- **信頼度 < 0.5**: ニュートラル維持

### アニメーション強度調整

```typescript
アニメーション強度 = 解析強度 × グローバル設定 × モデル固有係数
```

## パフォーマンス最適化

### 処理時間目標

- **解析処理**: 50ms 以内
- **キーワードマッチング**: 30ms 以内
- **アニメーション開始**: 100ms 以内

### メモリ管理

- **キーワード辞書**: 静的データ（初回読み込み）
- **解析履歴**: 循環バッファ（固定サイズ）
- **不要データ自動削除**: 1000 件解析毎
